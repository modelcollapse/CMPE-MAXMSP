CMPE Current / Inline Panels

Open CMPE_CURRENT.maxpat in Max 9.

  • Blue waveforms on a light background, auto-fit and VIEW × make quiet takes visible.
  • Drag the output or type START / END. AUTO LOOP repeats the range.
  • ADVANCED, TAPE + MEMORY, and EDIT / PREVIEW expand inline. EDIT / PREVIEW selects and auditions each source region. APPLY REGION uses it in the generators.
  • Monitor Volume: −72 to +18 dB.
